# Bills carry a final-value flag

A Bill gains an `isFinal` flag (sheet column `is_final`), set on the bill editor and off by default. It marks the amount as confirmed for the month. The Bills list flags a not-final bill with a ⚠️ before its name and groups not-final bills at the end of the list; copies made by replicate-last-month always arrive not final. The point is the workflow after a replicate: variable amounts (the card bill, utilities) are collected at the bottom, visibly awaiting this month's real value, without changing any total.

We rejected deriving finality from paid status — a bill can be paid before its value is confirmed, and a confirmed value can still be unpaid — and rejected a heavier "reviewed this month" workflow with its own screen or snapshot history for a marker this small. Extending the `bills` tab is additive and uses the established header-rewrite migration (prd.md "Sheet Initialization"): an existing sheet gains the column on its header row, and rows read back not final until written again.
